# What's new in Wivo 2.0.5

## Wivo now updates itself

From this version on, Wivo downloads new versions in the background and
installs them the next time you start it. Nothing to install by hand. Only
versions signed by Wivo are installed. **Settings → Licence** shows the
version you have and any version waiting.

## Smaller changes

- **Files on a job:** the buttons above the list (**All**, **Scan**,
  **Design**…) show one type of file at a time. "New files as" only sets the
  type of the files you add next.
- **Comments:** if a file you attached to a comment is cancelled or fails to
  upload, the comment no longer keeps loading. Remove the file with its ×.
- **On your phone:** a job can be deleted at the bottom of the job, with the
  same permission and the same "Delete? Yes" as on the desktop. A deleted job
  can be restored in Settings → Audit log.
- "What's new" now links to your clinic's own phone app:
  [{phoneHost}]({phoneUrl}).
