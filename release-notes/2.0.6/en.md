# What's new in Wivo 2.0.6

## Your first automatic update

If you are reading this after Wivo restarted by itself, the update worked:
Wivo downloaded this version in the background, checked that it was signed by
Wivo, and installed it the next time it started. You did nothing. **Settings →
Licence** shows the version you have.

## Smaller changes

- **What's new** now lists every version, newest on top, each under its own
  version heading. Scroll down to read the earlier ones.
