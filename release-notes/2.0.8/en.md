# What's new in Wivo 2.0.8

## Wivo's own name

Windows now shows Wivo by its proper name, **Wivo — dental clinic and lab
management**: on the shortcut, in the file's details and in the window title.
Before, it still carried an old working name.

## Updates from Wivo's new address

Wivo's updates now come from the Wivodent organisation on GitHub. Nothing
changes for you: Wivo checks for updates and installs them by itself, as
before, and still installs only what Wivo has signed.
